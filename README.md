# NontonKu

Prototype APK Android berbasis WebView.

## Cara build
Buka folder ini di Android Studio, tunggu Gradle sync, lalu Run/Build APK.

## Catatan penting
Prototype berisi katalog dan video demo. Untuk produksi, ganti katalog dengan API yang sah dan gunakan sumber video yang kamu miliki atau berizin. Metadata film bisa dihubungkan ke layanan seperti TMDB, tetapi TMDB sendiri tidak menyediakan file film untuk diputar.
